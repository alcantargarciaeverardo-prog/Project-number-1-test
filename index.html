Automatiza lo repetitivo. Publica más rápido.

MiProyecto es una herramienta de código abierto que configura, prueba y despliega tu proyecto con un solo comando.

Empezar ahora Dar una estrella

Licencia MIT · Versión 1.0.0 · Funciona en Windows, macOS y Linux

$ git clone https://github.com/tu-usuario/tu-proyecto
$ cd tu-proyecto
$ npm install
$ npm run start

✔ Proyecto listo en http://localhost:3000

Lo que hace por ti

  • Configuración en un minuto

    Sin archivos largos que editar. Los valores por defecto funcionan en la mayoría de proyectos.

  • Pruebas automáticas

    Ejecuta tus pruebas en cada cambio y muestra qué falló y dónde.

  • Despliegue con un comando

    Publica en GitHub Pages sin pasos manuales.

  • Extensible

    Agrega plugins propios o usa los que ya creó la comunidad.

Instala en tres pasos

  1. Clona el repositorio

    git clone https://github.com/tu-usuario/tu-proyecto.git

  2. Instala las dependencias

    npm install

  3. Inicia el proyecto

    npm run start
